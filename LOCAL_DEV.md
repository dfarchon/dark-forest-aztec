# LOCAL DEV

## Prerequisites

- Node.js `24.12.0`
- pnpm `10.28.0`
  - `corepack enable`
  - `corepack prepare pnpm@10.28.0 --activate`
- Aztec CLI toolchain available in PATH:
  - `nargo`
  - `aztec`
- Running Aztec node (default): `http://localhost:8080`
  - Start command: `aztec start --local-network`

## Quick Start

```bash
# 0. Start local Aztec node (in a separate terminal)
aztec start --local-network

# 1. Install dependencies
pnpm install

# 2. Build, deploy and configure contracts (first run / after contract changes)
cd contracts
pnpm start

# 3. Start frontend dev server
cd ../client
pnpm dev
```

Frontend runs on `http://localhost:5173` by default.

## Environment Variables

- `contracts/.env` is generated by deployment scripts and contains deployed addresses.
- Contract addresses are synced into `packages/contracts/src/index.ts`, then imported directly by the frontend.
- `AZTEC_NODE_URL` (default: `http://localhost:8080`)
- `PROVER_ENABLED=true` (default is `false`; enabling prover significantly slows deployment)

## Common Commands

| Command | Description |
| --- | --- |
| `pnpm install` | Install workspace dependencies |
| `cd contracts && pnpm start` | Full contract build + deploy + configure |
| `cd contracts && pnpm build-contracts` | Build contracts only |
| `cd contracts && pnpm sync-env-and-artifacts` | Sync deployed addresses/artifacts to packages |
| `cd client && pnpm dev` | Start frontend dev server |
| `cd client && pnpm build` | Frontend production build |
| `cd client && pnpm lint` | Run ESLint |
