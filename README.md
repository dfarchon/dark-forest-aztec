Dark Forest Aztec brings [Dark Forest v0.6](https://github.com/dfarchon/darkforest-v0.6) onto Aztec's private execution layer. Explore a procedurally generated universe, capture planets, command fleets, and compete for resources and glory. All game state lives in Noir contracts and proofs; hidden information remains truly hidden until you choose otherwise. This is only the beginning. We are building toward a future where programmable privacy reshapes what fully onchain games can be.

Do not rely on this for anything you cannot afford to lose.
